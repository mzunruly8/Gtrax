# Gtrax

**Pronunciation:** Gee-trax

## Description
Gtrax is a cosmic-chaotic matching puzzle game where players form paths, loops, and patterns using multiple match systems:

- Tap-to-match
- Drag-to-link
- Swipe-to-match

Inspired by the cosmos, constellations, and stellar energy flow.

## Run
Open `index.html` in any browser.
